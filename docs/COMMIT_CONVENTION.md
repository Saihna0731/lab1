# Commit Convention (Conventional Commits 1.0.0)

Энэ репод бүх commit доорх бүтцийг дагана:

```
<type>(<scope>): <товч тайлбар>

<биет — юуг, яагаад өөрчилсөн бэ (заавал биш)>

<footer — BREAKING CHANGE, issue холбоос (заавал биш)>
```

## 1. Type (заавал)

| Type       | Хэзээ хэрэглэх                                       | Жишээ |
|------------|------------------------------------------------------|-------|
| `feat`     | Шинэ боломж / шинэ алгоритм нэмэх                    | `feat(astar): A* алгоритм нэмэв` |
| `fix`      | Алдаа засах                                          | `fix(dfs): хязгааргүй давталт үүсэхийг зассан` |
| `docs`     | Зөвхөн баримт бичиг                                  | `docs(readme): суулгах заавар нэмэв` |
| `test`     | Тест нэмэх/засах                                     | `test(bfs): optimality-ийн тест нэмэв` |
| `refactor` | Үйлдэл өөрчлөгдөхгүй кодын бүтцийн засвар            | `refactor(core): Search дундын класс гаргав` |
| `perf`     | Гүйцэтгэлийн сайжруулалт                             | `perf(gbfs): heap ашиглаж хурдасгав` |
| `style`    | Формат, зай, нэршил (логик өөрчлөхгүй)               | `style(core): PEP8 форматлав` |
| `chore`    | Тохиргоо, хамаарал, туслах зүйл                      | `chore(env): requirements.txt нэмэв` |
| `build`    | Build/хамаарлын систем                               | `build: numpy хувилбар шинэчлэв` |
| `ci`       | CI тохиргоо                                          | `ci: pytest workflow нэмэв` |

## 2. Scope (заавал биш, гэхдээ зөвлөмжтэй)

Энэ лабораторид ашиглах scope-ууд:

`core` · `bfs` · `dfs` · `gbfs` · `astar` · `heuristics` · `grid` · `benchmark` · `viz` · `tests` · `docs` · `env`

## 3. Товч тайлбар (subject)

- 72 тэмдэгтээс хэтрэхгүй
- Цэгээр төгсгөхгүй
- Тушаах/өнгөрсөн цагийн тодорхой үйлдэл: «нэмэв», «зассан», «шинэчлэв»
- Жижиг үсгээр эхэлнэ (нэр томьёо биш бол)

## 4. Биет (body)

- Subject-ээс хоосон мөрөөр тусгаарлана
- **Юуг** биш **яагаад** гэдгийг тайлбарлана
- Мөр бүр 100 тэмдэгтээс хэтрэхгүй

## 5. Footer

- Эвдрэлтэй өөрчлөлт: `BREAKING CHANGE: Node.parent одоо Optional[Node]`
- Issue: `Closes #12`, `Refs #7`

## 6. Жишээ

```
feat(astar): A* алгоритм ба f = g + h үнэлгээ нэмэв

Priority queue-д (f, g, tie-breaker) гурвалыг ашиглан ижил f-тэй зангилаануудын
дарааллыг тогтвортой болгов. Ингэснээр benchmark давтагдах боломжтой.

Refs #4
```

```
fix(dfs): visited олонлог нэмж хязгааргүй давталтыг зассан

Цикл бүхий grid дээр DFS буцаж ирсэн зангилаа руу дахин ордог байв.

Closes #9
```

## 7. Branch нэршил

```
main                    — тогтвортой, шалгагдсан код
dev                     — хөгжүүлэлтийн үндсэн салбар
feature/<scope>-<тайлбар>   — feature/astar-implementation
fix/<scope>-<тайлбар>       — fix/dfs-infinite-loop
docs/<тайлбар>              — docs/lab-report
```

Ажлын урсгал: `feature/*` → `dev` → `main`

## 8. Commit template ашиглах

Репод `.gitmessage.txt` template тохируулагдсан. `git commit` (`-m` -гүй) гэж
бичихэд загвар нээгдэнэ.
